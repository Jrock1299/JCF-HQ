# Weekly Innovation Workflow

Run each Monday 9AM Romania:

1) If you shipped a concrete process improvement, log it as `completed`.
2) If not, log one actionable idea as `idea`.
3) Keep entries concise: title, action, measurable impact.

Command:

`python3 /root/.openclaw/workspace/scripts/weekly_innovation.py --status <completed|idea> --title "<short title>" --action "<what changed / next step>" --impact "<expected or measured impact>" --source "<web|reddit|x|local>"`

Log file:

`/root/.openclaw/workspace/memory/weekly_innovation_log.jsonl`
