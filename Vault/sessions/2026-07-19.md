# Session — 2026-07-19

## HQ dashboard performance pass (commit `eda3787`)

App felt sluggish in the browser. Diagnosed before fixing.

**Baseline measured:** single monolithic bundle **776.47 kB / 239.94 kB gz** JS
(1041 modules, zero code-splitting), 9.25 kB CSS. recharts = dominant weight
(9.4 MB in node_modules incl. all `d3-*` + `victory-vendor`), imported eagerly by
only Trading + Finances yet shipped to all 6 routes. All 22 `useHQData` calls were
on the 30s default — no 5s intervals anywhere. Orbs already GPU (transform x/y);
fonts already `display=swap`.

**Changes** (7 src files, see [[../infrastructure/hq-dashboard]] Performance section):
- `src/App.tsx` → `React.lazy` + `Suspense` for all 6 routes. recharts split into
  a lazy chunk loaded only on `/trading` + `/finances`.
- Blur trims in `globals.css` + `Layout.tsx` + `AgentHub.tsx` + `ChatBubble.tsx`
  (16–20px → 8–10px). Orb blur 48→32px + `will-change:transform` in `BackgroundOrbs.tsx`.
- `useHQData` default poll 30s → 60s (backend syncs every 2–5 min via cron).

**Result:** initial-route JS **776→~350 kB raw (240→~117 kB gz)**; recharts (~355 kB)
deferred off first paint. Rebuilt, `systemctl --user restart openclaw-hq`, curl `/`
→ 200, all 6 lazy chunks serve 200. Committed + pushed to `master`.

Note: `hq-app/dist/` is gitignored — only the 7 source files were committed; the VPS
build regenerates dist.
