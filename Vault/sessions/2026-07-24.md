### The one gotcha (worth remembering)
The task spec said to use `--model openai/gpt-5.5-codex`. That **fails** through
`openclaw agent`: `FailoverError: Unknown model … bound to the "codex" agent
runtime … served by an agent runtime, not models.providers`. The `-codex`
suffixed ids can't be passed as `--model` overrides. The working string is plain
**`openai/gpt-5.5`** (which is exactly what Jase reported testing successfully).
This is also why Lucy's `PRIMARY_MODEL = openai/gpt-5.3-codex` silently falls
back to `openai/gpt-5.5`.
