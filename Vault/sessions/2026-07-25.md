## Decisions

- **One gate, imported twice.** The brief said duplicate Norman's pipeline into
  both agents. Duplicating a *safety rail* is how rails drift. The gate lives once
  in `scripts/risk_validation.py`; each validator imports it and is tested
  independently (`--test-gate`, 4 rogue-synthesis cases). Both pass.
- **Regime briefings did NOT merge into Lens's 04:55 thesis.** The thesis is a
  once-daily Anthropic+web-search research product whose conclusions hold all day;
  the regime read is cheap, price-derived and session-scoped. A 04:55 regime read
  is ~7h stale by the NY open — exactly when Blade's NY_PM session reads it.
  Merging would either serve a stale regime or triple Lens's Anthropic spend.
  Result: one daily thesis (04:55), two regime briefings (06:00, 12:00), all Lens.
- **Victoria's scouting desk is default OFF.** Her weekly cron line is already
  live; defaulting the absorbed scout on would have activated it this Sunday
  without approval. Enable with `--with-scout` / `VICTORIA_WITH_SCOUT=1`.

## Bugs found and fixed along the way

- **Jarvis never actually read Lens's bias.** `read_lens_bias()` only looked for
  an `assets` dict, but `market_bias.json` stores a `pairs` **list** — so it
  silently returned `('neutral', 50)` every run. Fixed in `lens_regime.py`; SPX
  now resolves `bearish 67%` where it used to report `neutral 50%`.
- **The edge map was returning empty.** `build_edge_map` discards time slots with
  <10 samples; it was being fed 500 M15 bars (~5 days ≈ 5 samples/slot). Now
  fetches a dedicated 5000-bar series (~52 days ≈ 50 samples/slot).
- **Jerry's P&L is unpopulated.** All 90 closed positions carry `pnl: 0.0` — the
  field is never written on close. That sample would clear the 20-trade gate and
  grade **FAIL** (0% WR, PF 0, Sharpe 0) off a feed that reported nothing. Added
  an all-zero guard returning `NO_DATA` — extends Rule #9 into the validator.
  **Fixing `jerry_trader.py`'s close path is a separate open task.**
- **Norman's `--validate` CLI was passing a tuple as `trades`** and hardcoding a
  10,000 notional for Blade. Both fixed in the new validators; the weekly path
  was always correct.
