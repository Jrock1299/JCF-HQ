# 2026-07-17 — HQ Dashboard v3 rebuild (glass command center)

Full frontend rebuild of `hq-app/` — the deferred "HQ React dashboard redesign"
from the roadmap. Replaced the old JSX multi-page app (Dashboard / Basketball /
Investing / Projects / Timeline) with a 6-route glassmorphism command center.
Backend untouched (`serve_hq.py`, `hq_storage_server.py`).

## What changed
- **New stack:** React 18 + **TypeScript** + Vite, added `framer-motion`,
  `recharts`, `react-router-dom`. Fonts → Space Grotesk + JetBrains Mono.
  Added `tsconfig.json` / `tsconfig.node.json`. Build kept as `vite build`
  (esbuild) so type checks never block.
- **Clean rebuild:** deleted all old `.jsx` pages/components, `context/`,
  `api/`, old `hooks/`. Legacy `dashboard/*.json` data files left untouched.
- **6 routes:** Home, Trading (Blade + Jerry), Finances, Intelligence
  (Lens + Jarvis), Agent Hub, Agents. See [[../infrastructure/hq-dashboard]].
- **Design system** in `src/styles/globals.css`: glass surfaces (real blur),
  gold accent, drifting orbs, mono `// section` labels, gold-glow logo,
  emoji-fallback agent avatars.
- **Data layer** (`src/hooks/useHQData.ts`): same-origin relative URLs, 2.5s
  timeout, graceful fallbacks. Corrected the build spec, which assumed most
  endpoints live on `:8900` — in reality they're static `dashboard/*.json`
  files served by `serve_hq` on `:8899`; only `/hq/*` hits Flask.
- **Blade R computed** client-side (`src/data/derive.ts`) — learning log has
  no P&L field.
- **Agent Hub** (`src/data/seedMessages.ts`): in-character chat threads for all
  11 agents, typing-indicator → canned reply send flow. The soul of the app.

## Fixes caught in review
- `MiniSparkline` called a `useMemo` after an early return (rules-of-hooks
  violation → crash on empty data). Moved all hooks above the early return.

## Verify
- `npm run build` clean (bundle ~746 kB — Recharts; chunk-size warning only).
- `openclaw-hq.service` **started + enabled** (was disabled/inactive). All 6
  routes headless-render with signal text; 14 data files serve 200; data binds
  live ($958k net worth fallback, $101,784 Jerry live, $5,064 Blade live).
- `/hq/hub` returns 502 because `hq_storage_server` (:8900) is currently down —
  pre-existing, and the Hub runs off seed data so nothing breaks. Flagged to
  Jase to restart `hq-storage` if he wants POST-backed features live.
